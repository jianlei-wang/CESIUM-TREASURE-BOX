# 需求文档：综合态势标绘组件案例

## 1. 背景

案例库（cesium-toolbox-showcase）已有：

- 21 种军事几何标绘能力（`military-plotting-lib`：自由线/折线/曲线/自由面/多边形/正多边形/直线箭头/曲线箭头/直角箭头/燕尾箭头/钳击箭头/进攻箭头/圆角矩形/扇形/弓形/集结地/5 种旗标），单个 kind 独立案例与"编辑版"案例通过 `PlottingCaseShell.vue` 外壳呈现；
- 点线面矢量导出基础库（`draw-export-lib`，GeoJSON + SHP，WGS84/Web墨卡托/北京54/西安80 坐标系）。

本轮需求新增一个**综合态势标绘组件案例**：把"几何标绘 + 文本标注 + 图片标注 + 模型标注 + 编辑 + 成果标准导出"整合为一个可复用组件并注册为一张综合案例卡片，解决当前单 kind 案例分散、缺少标注类要素的问题。

## 2. 需求

### REQ-1：综合案例注册

- 新增案例 id 为 `situation-plotting`，分类 `draw`（标记标绘）。
- 标题、描述与 tag 反映"几何标绘 + 三类标注 + 编辑 + 标准导出"综合能力。
- 案例无图标（沿用新增案例默认无 icon 约定），等用户提供截图后补齐。

### REQ-2：几何标绘

- WHEN 用户在几何工具区选择任意一种标绘类型，THE 组件 SHALL 切换 `MilitaryPlottingSession` 进入该 kind 的绘制状态，且 21 种 kind（自由线/折线/曲线/自由面/多边形/正多边形/直线箭头/曲线箭头/直角箭头/燕尾箭头/钳击箭头/进攻箭头/圆角矩形/扇形/弓形/集结地/曲线旗标/矩形旗标/正三角旗标/倒三角旗标/对三角旗标）全部可选。
- 左键落点/成形、右键结束一笔的交互沿用既有约定；绘制完成的对象以 `military-plotting-` 前缀实体进入场景。
- 线宽（箭头类）、边数（正多边形）等按 kind 元信息显示对应参数。
- 提供统一"样式"（颜色/不透明度/线宽/边数）设置，绘制后已绘对象实时刷新样式。

### REQ-3：文本标注

- WHEN 用户选择"文本标注"工具并在地图单击，THE 组件 SHALL 在拾取位置创建文本标注实体（label）。
- 标注支持设置：文本内容、字号、字体颜色、背景/描边颜色、像素偏移（基于选取工具拖拽语义，提供属性面板编辑）。
- 文本标注实体带独立前缀 id，纳入统一对象清单。

### REQ-4：图片标注

- 图片来源支持三种方式（IF 本地上传 THEN 读取为可渲染 data URL / object URL；IF 输入网络 URL THEN 直接引用；内置预设图库按钮可切换预设图标）。
- 支持设置：图片源、缩放、旋转角、透明度。
- 图片标注实体带独立前缀 id，纳入统一对象清单。

### REQ-5：模型标注

- 内置两个模型入口（`public/data/model/metro_station/scene.gltf`、`public/data/model/launchvehicle/launchvehicle.gltf`），另支持网络 URL 与本地 .glb/.gltf(+资源) 上传。
- 支持设置：模型 URI、缩放、高度、朝向（heading）。
- 模型标注实体带独立前缀 id，纳入统一对象清单。

### REQ-6：编辑与交互

- 几何对象沿用 `PlotEditSession` 编辑能力（点选/顶点整形/移动/旋转/缩放/增删点/撤销）。
- WHEN 用户切换到"编辑标注"工具并点选文本/图片/模型标注，THE 组件 SHALL 显示选中态并允许：
  - 拖拽平移（按地表拾取逐帧更新位置）；
  - 旋转（图片绕锚点旋转、模型改 heading；文本不支持旋转则不显示该工具）；
  - 缩放（图片/模型缩放、文本字号调整）；
  - 属性面板编辑（按标注类型显示内容/来源/颜色/字号/尺寸/朝向等字段）。
- 几何编辑与标注编辑处于互斥工作模式，避免多 ScreenSpaceEventHandler 相互污染（沿用既有事件管理教训）。

### REQ-7：成果标准导出

- WHEN 用户执行导出，THE 组件 SHALL 把当前全部对象转换为 GeoJSON FeatureCollection：
  - 几何对象 → Polygon / LineString Feature（沿用 plot-edit exporter 的闭环/属性规则）；
  - 文本/图片/模型标注 → Point Feature，`properties` 携带标注类型、名称与关键属性（文本内容/图片 URL/模型 URI、字号/缩放/角度等）；
- 导出格式支持 GeoJSON 与 SHP；坐标系支持 WGS84 / Web墨卡托 / 北京54(3°带117°) / 西安80(3°带117°)。
- 点要素属性需进入 SHP 的 DBF 字段（增强 `draw-export-lib/shapefile.ts`，保持现有调用向后兼容）。
- 空场景执行导出时提示无对象。

### REQ-8：可复用组件形态

- 组件以可复用 `.vue` 组件 + 配套 session/类型模块交付（`src/cases/situation-plotting-lib/`），内部自建 viewer 生命周期；案例目录 `situation-plotting` 以薄壳引用。
- 组件卸载时释放 viewer、事件 handler、上传产生的 object URL。

### REQ-9：案例外观与文案

- 案例外观与文案不得出现"参考 / 移植 / 基于 <来源>"等来源表述。

## 3. 非目标

- 不修改 21 个单 kind 案例与 `military-plotting-lib` 既有行为（仅导出复用）。
- 不新增 Ion/其它第三方 token。
- 不引入额外前端依赖。
- 不做对象聚合/图层显隐/多方案叠加等超出本轮范围的编排能力。

## 4. 验收标准

1. `draw` 分类下出现「态势标绘」综合卡片，无图标。
2. 打开综合案例：可逐一切换 21 种几何 kind 并绘制；可创建文本/图片/模型标注（内置预设与上传均可用）。
3. 几何可编辑；标注可点选、拖拽平移并旋转/缩放/改属性。
4. 导出 GeoJSON / SHP：几何输出正确几何类型，标注输出 Point 且 DBF 含标注属性；4 种坐标系产物可解析。
5. `vue-tsc -b` 与 `npm run build` 通过（0 TS 错误），案例打开无 console 报错。
