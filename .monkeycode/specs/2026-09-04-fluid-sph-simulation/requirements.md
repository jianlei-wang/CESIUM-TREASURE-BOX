# 需求文档：SPH 地形流体模拟案例 + 水深图提取图标补齐

## 1. 背景

案例库（cesium-toolbox-showcase）持续扩充「水面效果」分类。本轮需要：

1. 为已有案例 `water-depth-extraction`（水深图提取）补齐卡片图标；
2. 新增 `fluid-sph` 案例：在真实 Cesium 地形上演示 GPU 端 SPH（光滑粒子流体动力学）地形流体模拟，作为水面效果方向的能力参考。

## 2. 需求

### REQ-1：水深图提取图标

- 卡片图标使用用户上传图（`.monkeycode-tmp-files/df01b465-image-1.webp`）。
- 图标以 256 尺寸 webp 形式存放于 `src/cases/water-depth-extraction/icon.webp`，复制后与源文件字节一致（md5 校验相同）。
- `index.ts` 引入 `icon.webp` 并写入 `icon` 字段，保证示例列表卡片 `<img>` 可渲染。

### REQ-2：fluid-sph 新案例

- 案例 id 为 `fluid-sph`，分类 `water`（水面效果），标题「SPH 地形流体模拟」。
- 场景包含真实地形、底图、地流体模拟运行与渲染：
  - GPU 端并行 SPH 粒子模拟（光滑核函数求解压力、重力、边界约束）；
  - 多缓冲 compute 逐帧推进水位场；
  - 体积光线步进渲染水面（Fresnel、深度颜色渐变、水下颜色衰减）。
- 交互与参数：
  - 点击地形可移动水源位置；
  - 水源添加速率、水源半径、重力强度、初始水位、渲染质量、水不透明度、浅/深水颜色可调；
  - 可暂停/继续与重置模拟。
- 案例外观与文案不得出现「参考 / 移植 / 基于 <来源>」等来源表述。
- 案例图标本轮不设置（沿用「不生成 icon」约定），等用户提供截图后补齐。

## 3. 非目标

- 不新增 Ion/其它第三方 token。
- 不修改 `flood-sim-lib` 既有案例行为（仅导出其内部通用 primitive 类供复用）。
- 不把外部库/仓库名称写入展示文案。

## 4. 验收标准

1. 列表页「水面效果」分类下出现「水深图提取」卡片且带可渲染图标；「SPH 地形流体模拟」卡片存在、无图标。
2. 打开 SPH 案例：页面无着色器编译 / primitives 崩溃类错误，面板与模拟正常推进，暂停后可恢复。
3. 生产构建通过（`npm run build`）。

## 5. 增补需求（V6.5）

### REQ-3：全量来源表述清理

- 代码注释、卡片、面板与提示文案中不得残留任何参考仓库名 / 昵称、shadertoy 示例 id，以及「参考 / 移植 / 基于 <来源>」类引导语。

### REQ-4：默认重力与贴地矩形绘制

- 重力强度默认值改为 `1`（可调范围 `0.1`~`10`）。
- 面板提供「绘制区域」：进入框选模式后，首次点击确定第一角点，移动鼠标实时预览贴地矩形（半透明填充 + 描边），再次点击完成框选。
- 框选完成后，对该范围实时采样 Cesium World Terrain 高程（网格上限约 256×(≤512)），生成与静态高度图编码一致的 1024×1024 高度图，用新 extent / min-max / 高度图就地重建模拟与体积盒，相机飞入该区域。
- 框选范围过小（经纬度边长 < 0.0015°）或采样失败时给出提示且不破坏当前模拟；右键点击或再次点击按钮取消框选。
- 「重置」返回默认 Yosemite 区域（静态高度图）。

### REQ-5：水流方向箭头显隐

- 面板提供「流向箭头」开关，可在水面上叠加 / 隐藏示意水体运动方向的箭头；箭头来自表面平滑阶段的平均速度场，只出现在有水体处，默认关闭。
- 暂停 / 继续不应改变箭头显隐状态。

### 验收补充

1. `gravity` 滑块默认显示 `1.0`。
2. headless：进入案例无 shader / primitive 错误；开启「绘制区域」后按钮文案切换为「取消框选」，再次点击退出；勾选 / 取消「流向箭头」无 console 错误。
3. `vue-tsc -b` 与 `npm run build` 均通过。
