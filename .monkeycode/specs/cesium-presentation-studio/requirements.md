# Cesium 三维场景演示漫游制作系统 · 需求映射

来源：`e8dae1d2-Cesium三维场景演示漫游（Presentation）功能PRD文档(1)-1.docx`

## 1. 产品边界

以「演示工程 → Step → Action」三层结构编排 Cesium 场景镜头，支持编辑、预览、播放、导出、持久化。完全独立实现，不引用仓库内既有演示案例的任何运行时代码。

## 2. 逐条需求映射

| PRD 条目 | 实现要求 | 验收点 |
| --- | --- | --- |
| 3.1.1 新建演示 | 空白工程，默认 1 个空白 Step，可填名称/备注 | 新建后左侧出现 Step 01，工程可命名 |
| 3.1.2 保存/另存 | 覆盖保存 + 另存为新工程 | 保存后工程库出现/更新记录，另存生成独立 ID |
| 3.1.3 导入导出 | `.cesium.presentation`，JSON 全量数据 | 导出再导入后步骤、动作、相机、字幕、图层完全一致 |
| 3.2.1 步骤操作 | 新增/删除/上移/下移/复制/重命名 | 所有操作即时反映在时间轴与总时长 |
| 3.2.2 步骤参数 | 时长、漫游速度、过渡效果、停留时长 | 参数变更后时间轴重算，越界值自动收敛 |
| 3.3 动作编排 | 串行执行、拖拽排序、启用/禁用、复制/删除、独立时长 | 播放顺序与列表顺序一致，禁用动作不参与时间轴 |

| 3.3.2 场景效果 | 阴影、光照、雾、大气、等高线、坡度 | 开关实时生效，可被动作编排 |
| 3.3.3 字幕弹窗 | 全屏/上下左右/定点字幕，字体、颜色、大小、停留 | 播放和导出均可见，带淡入淡出 |

| 3.3.4 动作通用 | 拖拽、删除、复制、启用、独立时长、串行 | 动作列表交互完整，时间轴计算一致 |
| 3.4 播放控制 | 播放/暂停/停止/重播、单步、0.5–2x、进度拖拽、结束复位 | 拖动进度条可确定性重建任意时刻场景 |
| 3.5 视频导出 | MP4、1080P/2K/4K、30/60fps、进度、取消、保留效果 | 导出画面包含三维场景、字幕、弹窗、章节转场 |
| 3.6.1 存储字段 | 工程信息、步骤、动作、相机、图层、字幕、时序 | JSON 字段完整，可二次编辑 |
| 3.6.2 存储方式 | 本地草稿、文件导出、可选后端 | 自动草稿恢复，未保存离开提示 |
| 4.1 编辑器布局 | 左工程+步骤、中场景、右参数、底部播放/导出 | 1440×900 及 1280×800 下无遮挡 |

## 3. 非目标

- 后端团队共享存储（PRD 标注可选）。
- 服务端视频转码；浏览器不支持 MP4 录制时给出 WebM 降级与明确提示。
- 真实 GIS 图层目录服务，本案例使用内置影像、地形与大雁塔 3D Tiles。

## 4. 验收基线

1. 打开案例即加载内置演示工程，可直接播放完整 5 幕演示。
2. 所有动作类型均可新增、编辑、排序、启停、复制、删除。
3. 任意进度跳转后画面状态与连续播放一致。
4. 导出视频包含三维画面与字幕/弹窗/章节层。
5. 刷新页面后未保存草稿可恢复，工程导入导出可完整往返。
