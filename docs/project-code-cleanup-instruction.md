# 项目代码清理标准指令

## 目标

对当前项目执行一次可审计、可回滚、以证据为基础的代码清理，降低无效代码、重复实现、过时依赖和资源浪费，同时保持现有功能、路由、案例注册和构建流程稳定。

## 执行原则

1. 先扫描、分类和记录证据，再提出删除候选。
2. 删除动作需要明确的引用证据和人工确认。
3. 动态引用、反射调用、字符串路径、模板动态组件、配置驱动入口、资源 URL、Cesium shader/fabric 引用和异步 `import()` 均进入人工确认清单。
4. 保留公共模块、案例注册入口、生命周期清理逻辑、必要的兼容代码和运行时兜底。
5. 清理过程保留可回滚边界，每轮只处理一组相关文件。
6. 报告中禁止输出 API token、密码、Cookie、私钥和完整环境变量值。

## 清理范围

- 未被引用的 Vue 组件、TypeScript 模块、样式和静态资源
- 重复的 Cesium Viewer 初始化、底图加载、错误处理和销毁逻辑
- 已迁移后遗留的地图服务工具、常量和配置
- 未使用的 npm 依赖、脚本和 Vite 配置项
- 无效的 CSS 选择器、重复样式和无效资源路径
- 调试输出、临时注释代码和失效的 TODO
- 文档中与当前代码、版本或运行命令不一致的内容

## 排除范围

- `.git/`、`node_modules/`、构建产物和缓存目录
- 用户明确保留的兼容入口、示例资源和历史记录
- 通过动态字符串、运行时注册或外部配置访问的模块
- 无法证明安全删除的 Cesium 资源、credit、provider 和生命周期代码
- 含有凭据的文件内容。此类文件只报告文件路径、变量名和风险等级。

## 标准流程

### 1. 建立基线

记录当前分支、工作区状态、Node.js/npm 版本、依赖锁文件状态和可用脚本。执行清理前保留构建基线结果。

```bash
git status --short
npm run build
git diff --check
```

### 2. 扫描候选项

使用项目已有工具扫描文件、导入关系、路由、案例注册、动态引用、依赖和资源。每个候选项记录文件、符号、引用位置、证据、风险和建议动作。

候选分类使用以下标签：

- `SAFE_CANDIDATE`：静态搜索和构建结果共同证明可删除
- `REVIEW_REQUIRED`：存在动态引用、配置引用或跨模块影响
- `KEEP_REQUIRED`：公共入口、运行时依赖、兼容逻辑或必要资源
- `SECURITY_REVIEW`：可能包含凭据、敏感配置或外部访问信息

### 3. 分析依赖影响

对每个 `SAFE_CANDIDATE` 检查：

- 是否被路由、案例注册表、模板、测试或脚本引用
- 是否通过 `import()`、`new URL()`、字符串路径或配置文件间接引用
- 是否承担全局初始化、Viewer 销毁、事件解绑或异步竞态保护
- 是否包含 public 资源、Cesium worker、shader、terrain、imagery 或 credit 依赖
- 删除后是否会改变用户可见功能、构建产物或运行时错误处理

### 4. 生成变更清单

执行修改前输出清单，至少包含：

| 文件 | 符号或依赖 | 分类 | 删除或保留理由 | 影响 | 需要确认 |
| --- | --- | --- | --- | --- | --- |

清单中每个删除项需要给出可复核的搜索结果或构建证据。对于 `REVIEW_REQUIRED` 项，只提出建议并等待人工确认。

### 5. 分批执行

每批只处理同一模块或同一类问题。修改后立即检查引用、类型、构建和差异。保留清晰的提交边界，便于单批回滚。

### 6. 验证

```bash
npm run build
git diff --check
git status --short
```

对 Cesium 案例额外验证：

- 案例可以从案例中心进入并正常返回
- Viewer、地形 provider、imagery layer、后处理阶段和事件监听器在卸载时释放
- 动态资源加载完成后不会写入已销毁的 Viewer
- 地图、面板、状态遮罩和移动端布局没有重叠或空白
- 必要的 Bing、Cesium Ion、terrain 和 shader credit/资源行为符合产品要求

### 7. 输出收益报告

报告包含删除文件数、删除代码行数、依赖变化、构建产物变化、风险项、保留项和待确认项。任何凭据风险只输出脱敏后的变量名、文件路径和修复建议。

## 当前项目特别检查项

- 对旧地图服务工具执行全仓库引用搜索，引用为零且无动态访问证据时列为 `SAFE_CANDIDATE`。
- 对 `src/cases/index.ts`、案例目录 `index.ts` 和动态案例加载逻辑执行人工确认。
- 对 `src/lib/cesium-scene.ts` 的 Viewer 初始化、Ion 配置、底图加载和销毁函数执行人工确认。
- 对地形案例的 `createWorldTerrainAsync`、terrain provider 切换、垂直夸张和 credit 显示执行人工确认。
- 对 `.env*`、配置文件和源码中的凭据执行 `SECURITY_REVIEW`，报告中禁止展示真实值。

## 完成标准

- 所有删除项均有证据和变更记录。
- 所有动态引用和运行时依赖均完成确认。
- `npm run build` 通过。
- `git diff --check` 通过。
- 关键案例可进入、可运行、可卸载。
- 清理收益和遗留风险已记录到项目文档。
