# 本地表格点图层需求

## 简介

新增“数据图层-表格点位”案例，读取浏览器本地表格文件，按用户选择的经纬度字段生成随机颜色点，并提供图层管理和属性查看能力。

## 需求

### 需求 1：本地表格读取

1. 当用户选择 CSV、TSV、TXT、XLS、XLSX、XLSM、XLSB 或 ODS 文件时，系统应解析全部可用工作表并显示工作表选择项。
2. 当用户选择一个或多个工作表时，系统应仅为选中的工作表准备点图层。
3. 当多个工作表同时待加载时，系统应为每个工作表分别显示经度、纬度和标注字段选择器。
4. 当表格缺少可用工作表或数据记录时，系统应显示可读错误信息。

### 需求 2：点图层加载

1. 当用户为每个选中工作表选择经度和纬度字段并加载数据时，系统应为每条有效坐标记录创建地图点。
2. 系统应为每个图层分配一种随机颜色，并使同一图层中的所有点使用该颜色。
3. 系统应为不同图层分配不同的随机颜色，并保留完整表格属性。
4. 当用户为某个工作表选择标注字段时，系统应仅在该工作表对应点旁显示该字段值。

### 需求 3：图层与属性管理

1. 系统应显示图层名称、格式和点数量，并支持显隐、标注显隐、跳转和移除。
2. 当用户点击地图点时，系统应显示该记录的完整属性键值。
3. 当用户关闭案例时，系统应销毁 Viewer、点击监听器和已加载数据源。
