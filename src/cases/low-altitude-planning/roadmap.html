项目概述

1.1 项目背景与政策环境

低空经济是以民用有人驾驶和无人驾驶航空器为载体，辐射带动相关领域融合发展的综合性经济形态，已被列为国家战略性新兴产业。随着《无人驾驶航空器飞行管理暂行条例》（国务院、中央军委令第761号，2023年公布，2024年1月1日起施行）的落地，低空空域管理、飞行活动审批、实名登记、运行识别等要求逐步明确，各地低空飞行服务保障体系（飞行服务平台、空域管理、航线规划、飞行监控）建设进入加速期。

条例明确将真高120米以上空域，空中禁区、空中限制区及周边空域，机场及周边、军事禁区、监管场所、重要军工设施、核设施、易燃易爆危险品生产仓储区域、发电厂/变电站/加油（气）站、重要革命纪念地等特定区域上空划设为管制空域；管制空域以外的空域为微型、轻型、小型无人驾驶航空器适飞空域，适飞空域内的常规飞行活动原则上豁免飞行活动申请。这一“管制空域+适飞空域”的分级管理体系，要求低空管理系统具备空域数字化表达、网格化管控、航线智能规划、飞行计划审批和实时监控等核心能力。

与此同时，空域数字化普遍采用全球剖分网格体系（如GeoSOT北斗网格码）实现“把天空切成可编号、可检索、可计算的三维网格”，支撑禁飞/限飞/适飞区域的精细化管理，以及无人机飞行路径与空域网格的碰撞、占用和冲突检测。本方案即面向上述需求，基于CesiumJS 1.144三维地球引擎建设低空规划系统。

1.2 参考视频产品功能分析

为确定系统功能边界与页面形态，对“EasyGlobe（易景）| Web3D | Cesium低空场景”系列演示视频进行了逐帧分析。三个视频均为无配音的产品演示，画面展示了同一平台的不同能力页。分析结论如下。

1.2.1 视频一：Cesium低空场景网格可视（BV1jytd6ZEwo，61秒）

该视频演示低空场景的多源数据网格可视化能力，页面要素包括：

  • 系统一级导航：场景模块管理、基础数据管理、申请审批、任务调度、飞行监控、业务台账；
  • 场景控制面板：单值渲染、分级渲染、点云渲染、热力图、轨迹图五种渲染模式，均带阈值参数（如0.001）；
  • 场景树管理：基础图层（地形、路网、建筑、POI），以及道路网络、路网密度、设施分布、热力图、动态轨迹、视频融合等专题图层；
  • 多源网格分析、动态路网规划、场景路网可视、移动态势分析、动态路网预测等功能页；
  • 性能指标展示：数据规模8000+、渲染耗时44.204ms、加载进度100%、区域范围约47.58km×55.38km等，并标注“北斗2025”标识。

可提炼的核心能力：低空场景按图层组织、按网格单元表达、支持多种渲染模式与性能监控，是“场景网格可视”模块的原型。

该视频演示航线智能规划与相关分析功能，页面要素包括：

  • 分析专题：网络拓扑可视、静态风险分析、动态风险预测、应急指挥调度、单体楼宇分析、路网分析。

可提炼的核心能力：航线规划（航点/障碍/高度层）、空域申请、电子围栏、轨迹与统计分析、净空风险分析，是“航线智能规划”模块的原型。

1.3 系统定位与建设目标

系统定位：面向低空飞行服务保障的一体化Web3D规划与管控平台，以CesiumJS 1.144为三维底座，覆盖“空域数字化—网格可视—航线规划—模拟飞行—实时监控—业务闭环”全链路。

  • 场景网格可视：基于GeoSOT网格实现低空空域与地面要素的数字化、可视化、可检索；
  • 航线智能规划：支持多任务类型的航线自动生成、避障平滑、多约束评估与方案比选；
  • 航线模拟飞行：支持规划航线三维仿真飞行、姿态与相机控制、HUD参数展示与回放；
  • 实时监控与告警：接入真实/模拟轨迹，实现航迹、设备、空域占用、越界与冲突的实时监控告警；
  • 业务闭环：空域申请、任务调度、飞行计划审批、业务台账、统计报表的一体化管理；
  • 性能目标：常规场景流畅交互（≥30FPS），支持万级实体与十万级网格单元的渲染调度。

总体架构设计

2.1 设计原则

  • 分层解耦：表现层、应用服务层、数据服务层、数据资源层相互独立，接口契约化，支持前后端并行开发；
  • 数据驱动：三维场景完全由数据（图层配置、网格、航线、轨迹、告警）驱动渲染，业务变化不改代码；
  • 标准开放：遵循OGC标准（3D Tiles、WMTS、GeoJSON），支持与外部低空平台、UOM/UTM系统对接；
  • 性能优先：大规模网格与实体采用Primitive/实例化/瓦片化方案，避免Entity对象膨胀；
  • 安全合规：满足等保2.0要求，实名认证、飞行数据加密存储与审计，符合《无人驾驶航空器飞行管理暂行条例》数据管理要求；
  • 可扩展：模块化、插件化设计，预留气象、通信、第三方数据接入能力。

2.4 部署架构

系统以政务/企业内部网络部署为主，支持互联网接入。部署要点：

  • Nginx作为统一入口：托管前端静态资源、反向代理后端API与WebSocket、HTTPS终止、静态瓦片缓存；
  • 后端服务集群：无状态设计，多实例水平扩展，Session外置Redis；
  • 数据库：PostgreSQL主从复制，定时全量+WAL增量备份；
  • 消息与实时：Kafka集群承载轨迹流，WebSocket网关集群承载前端推送；
  • 三维数据：3D Tiles瓦片与影像部署在MinIO/瓦片服务，Nginx缓存加速；
  • 安全：防火墙分区、API网关统一鉴权、操作审计日志、数据库脱敏与备份策略，满足等保2.0三级基本要求。

6.3 GeoSOT网格可视化实现

核心思路：把空域范围按目标层级递归剖分为网格单元，每个网格用一个BoxGeometry（三维盒体）或沿地表 Polygon表达，使用Primitive批量渲染以获得性能（万级网格不掉帧）；编码与状态来自后端，前端只负责渲染与拾取。

// 网格Primitive批量渲染（示意） function buildGridPrimitive(cells, viewer) { const instances = []; const colorMap = { free: Cesium.Color.GREEN, used: Cesium.Color.ORANGE, forbid: Cesium.Color.RED }; for (const c of cells) { const rect = Cesium.Rectangle.fromDegrees(c.west, c.south, c.east, c.north); const hMin = c.altMin, hMax = c.altMax; const box = new Cesium.BoxGeometry({ minimum: new Cesium.Cartesian3( Cesium.Math.toRadians(c.west), Cesium.Math.toRadians(c.south), hMin), maximum: new Cesium.Cartesian3( Cesium.Math.toRadians(c.east), Cesium.Math.toRadians(c.north), hMax), vertexFormat: Cesium.VertexFormat.POSITION_AND_NORMAL }); const geom = Cesium.BoxGeometry.createGeometry(box); instances.push(new Cesium.GeometryInstance({ geometry: geom, modelMatrix: Cesium.Transforms.eastNorthUpToFixedFrame( Cesium.Cartesian3.fromDegrees((c.west+c.east)/2,(c.south+c.north)/2, (hMin+hMax)/2)), attributes: { color: Cesium.ColorGeometryAttribute.fromColor(colorMap[c.state]||Cesium.Color.GREY) }, id: c.code })); } const p = new Cesium.Primitive({ geometryInstances: instances, appearance: new Cesium.PerInstanceColorAppearance({ translucent: true, flat: true }) }); viewer.scene.primitives.add(p); return p; } // 网格拾取 const handler = new Cesium.ScreenSpaceEventHandler(viewer.scene.canvas); handler.setInputAction((e) => { const picked = viewer.scene.pick(e.position); if (picked && picked.id) console.log('网格编码：', picked.id); }, Cesium.ScreenSpaceEventType.LEFT_CLICK);

性能要点：网格超过10万级时建议服务端按层级聚合返回（LOD），或使用GeometryInstance批量合并；三维盒体仅对需要显示高度属性的层级开启，平面场景用PolylineGeometry+GroundPrimitive贴地渲染。

6.4 航线智能规划算法

规划算法采用“空间网格化 + 双层搜索 + 曲线平滑”路线：

  • 障碍与空域约束栅格化：将禁飞区、限高区、建筑体按GeoSOT网格（或自定义网格）栅格化为不可通行/代价加权的三维体素；
  • 全局搜索：A*（网格地图，保证确定性）与RRT*（连续空间采样，用于复杂障碍）双算法，按场景自动选择或并行生成；
  • 局部平滑：B样条平滑全局折线，Dubins路径约束转弯半径，输出满足机型机动性的可飞轨迹。
// A*网格搜索（核心示意：二维网格+高度分层） function aStar(grid, start, goal) { const open = new MinHeap(); const g = new Map(), parent = new Map(); open.push({ f: 0 + h(start, goal), g: 0, node: start }); g.set(key(start), 0); while (!open.empty()) { const cur = open.pop().node; if (cur === goal) return reconstruct(parent, cur); for (const nb of neighbors(grid, cur)) { // 上下左右 + 高度层变化 if (!passable(grid, nb)) continue; const ng = g.get(key(cur)) + cost(cur, nb); if (ng < (g.get(key(nb)) ?? Infinity)) { g.set(key(nb), ng); parent.set(key(nb), cur); open.push({ f: ng + h(nb, goal), g: ng, node: nb }); } } } return null; // 无可行路径 } // B样条平滑（Douglas-Peucker + 三阶B样条示意） function bsplineSmooth(pts, degree = 3) { // 对A*折线先做抽稀，再按累积弦长参数化生成B样条控制点 const knots = chordLengthKnots(pts, degree); const sampled = []; for (let t = 0; t <= 1.0001; t += 0.02) { sampled.push(deBoor(pts, knots, degree, t)); } return sampled; } // Dubins曲线（固定转弯半径R的航向约束衔接） function dubins(p0, heading0, p1, heading1, R) { // 返回 LSL / RSR / LSR / RSL 四种候选中最短的一条圆弧+直线段路径 return shortestOf(dubinCandidates(p0, heading0, p1, heading1, R)); }

参数建议：网格粒度默认100m×100m×20m（可按机型与场景调整）；A*启发式采用三维欧氏距离；对多任务并行规划使用后端线程池，结果以GeoJSON返回前端渲染候选方案。

6.5 模拟飞行实现

基于Cesium Clock时间轴 + SampledPositionProperty + VelocityOrientationProperty实现规划航线的三维模拟飞行，支持播放/暂停/倍速/拖拽回放。

// 模拟飞行核心代码（Cesium 1.144） function playRoute(viewer, routePoints) { const start = Cesium.JulianDate.now(); const stopTime = Cesium.JulianDate.addSeconds( start, routeDuration(routePoints), new Cesium.JulianDate()); viewer.clock.shouldAnimate = true; viewer.clock.startTime = start.clone(); viewer.clock.stopTime = stopTime.clone(); viewer.clock.currentTime = start.clone(); viewer.clock.multiplier = 8; // 8倍速 viewer.timeline.zoomTo(start, stopTime); const position = new Cesium.SampledPositionProperty(); for (let i = 0; i < routePoints.length; i++) { const t = Cesium.JulianDate.addSeconds(start, routePoints[i].t, new Cesium.JulianDate()); position.addSample(t, Cesium.Cartesian3.fromDegrees( routePoints[i].lon, routePoints[i].lat, routePoints[i].alt)); } const entity = viewer.entities.add({ position: position, orientation: new Cesium.VelocityOrientationProperty(position), model: { uri: '/models/uav.glb', scale: 2, heightReference: Cesium.HeightReference.NONE }, path: { resolution: 10, width: 3, material: new Cesium.PolylineGlowMaterialProperty({ color: Cesium.Color.CYAN, glowPower: 0.2 }) }, label: { text: 'UAV-001', pixelOffset: new Cesium.Cartesian2(0, -46), scale: 0.7 } }); // 相机跟随 viewer.entities.add({ position: position, viewFrom: new Cesium.Cartesian3(30, -50, 25) // 第三视角跟随 }); viewer.trackedEntity = entity; return entity; } // HUD参数实时更新 const onTick = () => { const pos = entity.position.getValue(viewer.clock.currentTime); const vel = entity.orientation.getValue(viewer.clock.currentTime); // 计算经纬度/海拔/速度/航向，更新HUD面板DOM };

回放历史轨迹时使用同一套Clock机制，仅将采样数据替换为track_point表历史数据（时间戳为真实时间），即可实现“历史轨迹回放”。

6.6 实时数据链路（航迹/设备/告警）

实时链路采用“设备/仿真源 → Kafka → 后端状态服务 → WebSocket/MQTT → 前端Cesium渲染”架构。

// 后端：航迹消息推送（Spring Boot WebSocket示意） @Component public class TrackSender { private final SimpMessagingTemplate template; private final KafkaConsumer consumer; @KafkaListener(topics = "uav-track") public void onTrack(TrackMsg msg) { // 1) 实时状态缓存 Redis hash uav:track:{deviceNo} redis.opsForHash().put("uav:track:" + msg.getDeviceNo(), "t:" + msg.getT() + ":lon:" + msg.getLon() + ":lat:" + msg.getLat()); // 2) 越界/冲突检测（可异步线程池） List alarms = detector.check(msg); // 3) 推送给订阅前端（按区域/设备分组 topic） template.convertAndSend("/topic/track/" + msg.getDeviceNo(), msg); alarms.forEach(a -> template.convertAndSend("/topic/alarm", a)); } }
// 前端：WebSocket接入与轨迹更新 const ws = new WebSocket('wss:///ws/track'); const sample = new Cesium.SampledPositionProperty(); // 实时缓冲2分钟 ws.onmessage = (e) => { const m = JSON.parse(e.data); // {deviceNo,lon,lat,alt,speed,heading,t} const cart = Cesium.Cartesian3.fromDegrees(m.lon, m.lat, m.alt); const jd = Cesium.JulianDate.fromDate(new Date(m.t)); sample.addSample(jd, cart); updateEntity(m.deviceNo, cart, m); // 实体位置直接setValue平滑 checkAlarm(m); // 前端快速越界预判 }; // 前端高频更新使用 callbackProperty 平滑： entity.position = new Cesium.CallbackProperty((time, result) => { return sample.getValue(time, result); }, false);

6.7 冲突与越界检测设计

  • 静态检测：航线与禁飞区/围栏使用PostGIS ST_Intersects + 网格占用表一次性校验（规划期）；
  • 动态检测：实时航迹在Redis网格占用表标记“网格编码+时间片+设备”，新轨迹查询时空交集；网格占用采用时间片轮转表（如5秒一个时间片），支持亚秒级并发判断；
  • 前端辅助：Turf.js做轻量越界预判（点在多边形），减少服务端压力；
  • 告警分级：越界/冲突=紧急（红），偏离航线=警告（橙），低电量/信号弱=提醒（黄），全部落alarm_log并联动处置。

6.8 前端工程化与性能优化

  • 代码组织：目录按 modules（场景/规划/飞行/监控）+ core（Cesium封装）+ shared 划分；Cesium Viewer封装为单例可注入模块；
  • 分包加载：Cesium核心包单独chunk，业务代码按页面懒加载；
  • 渲染优化：大数据使用Primitive/Instance、关闭不必要特效、requestRenderMode按需渲染、远裁剪面与LOD策略、地形/影像瓦片缓存；
  • 内存治理：图层销毁时移除Entity/Primitive并释放数据源；轨迹缓冲按时间窗滑动裁剪；
  • 多线程：网格剖分、热力统计等CPU密集计算放Web Worker，避免阻塞主线程。
